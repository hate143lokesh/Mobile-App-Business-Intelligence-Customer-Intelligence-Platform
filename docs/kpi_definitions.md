# Business KPI Definitions

| KPI | Definition | Business Purpose |
|---|---|---|
| Total Registered Users | Total registered customers | Measure customer base |
| Active Users | Users active during a defined period | Measure engagement |
| Churn Rate | Churned customers / eligible customers × 100 | Measure customer loss |
| Retention Rate | Retained customers / eligible starting customers × 100 | Measure retention |
| Conversion Rate | Customers who purchased / eligible targeted customers × 100 | Measure campaign effectiveness |
| Average Order Value | Total revenue / number of orders | Measure average order value |
| Purchase Frequency | Number of orders / number of customers | Measure purchase behaviour |
| Average Session Duration | Total session duration / number of sessions | Measure engagement |
| Repeat Purchase Rate | Customers with repeat purchases / purchasing customers × 100 | Measure loyalty |

## Important KPI Rules

1. Every KPI must have a clearly defined numerator and denominator.
2. The time period must be specified.

3. Customer eligibility must be defined.
4. Churn and retention definitions must be agreed with the business.
5. Avoid comparing KPIs calculated using different definitions or time periods.

## Initial Churn Definition Proposal

A customer may be classified as churned if they have not performed a meaningful app activity for 30 consecutive days.

This is a proposed definition and must be validated with the business before model development.
