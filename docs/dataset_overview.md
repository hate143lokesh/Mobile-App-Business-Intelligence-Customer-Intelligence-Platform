# Dataset Overview

## 1. Dataset Name
Indian E-Commerce Customer Behavior & Purchase Dataset

## 2. Dataset Source
Kaggle

## 3. Dataset Size
- Total Records: 25,000
- Total Columns: 29
- File Format: CSV
- File Name: Ecommerce.csv

## 4. Data Type
Synthetic e-commerce customer interaction data.

## 5. Main Data Categories
- Customer and session information
- Marketing information
- Product and purchase information
- Customer behaviour
- Customer feedback
- Date and analytical features

## 6. Business Problems We Can Analyse
- Purchase conversion
- Cart abandonment
- Marketing channel performance
- Product category performance
- Customer behaviour
- Customer segmentation
- Customer feedback and sentiment

## 7. Dataset Limitations
- Data is synthetic, not verified real company data.
- Long-term customer churn cannot be directly established from this dataset.
- Customer location and category codes require a data dictionary for interpretation.
