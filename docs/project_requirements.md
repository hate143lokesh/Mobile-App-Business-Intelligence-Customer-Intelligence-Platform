# Project Objectives and Requirements

## 1. Primary Objectives

1. Analyze customer purchasing and engagement behaviour.
2. Identify patterns associated with customer churn.
3. Develop a model to predict customer churn.
4. Segment customers according to their behaviour.
5. Predict customer marketing conversion.
6. Analyze customer reviews using NLP.
7. Build a personalized product recommendation system.
8. Create interactive Power BI dashboards.
9. Provide actionable business recommendations.

## 2. Functional Requirements

| ID | Requirement | Priority |
|---|---|---|
| FR01 | Import customer data | High |
| FR02 | Clean and validate datasets | High |
| FR03 | Analyze customer activity | High |
| FR04 | Calculate business KPIs | High |
| FR05 | Predict customer churn | High |
| FR06 | Segment customers | High |
| FR07 | Predict marketing conversion | Medium |
| FR08 | Analyze customer sentiment | Medium |
| FR09 | Recommend relevant products | Medium |
| FR10 | Display analytical results in Power BI | High |
| FR11 | Expose model predictions through APIs | Medium |

## 3. Non-Functional Requirements

- Data quality and consistency.
- Reliable model predictions.
- Secure handling of customer information.
- Reproducible analysis.
- Maintainable project structure.
- Clear documentation.
- Appropriate model evaluation.

## 4. Technology Requirements

- VS Code
- Python
- Excel
- SQL
- Power BI
- Pandas and NumPy
- Scikit-learn
- XGBoost or LightGBM
- NLP and Deep Learning libraries when required
- FastAPI

## 5. Project Success Criteria

- Complete and validated analytical datasets.
- Business KPIs calculated correctly.
- Models evaluated using suitable metrics.
- Customer segments that can be interpreted.
- Interactive Power BI dashboards.
- Actionable recommendations supported by analysis.

Actual business improvement will need to be validated through a real intervention or controlled experiment.
